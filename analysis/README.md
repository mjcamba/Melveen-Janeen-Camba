# Analysis

This directory contains the analysis for the project.

- [`marginal-analysis-findings.md`](marginal-analysis-findings.md) — what the
  farm optimization model shows: why tomatoes stop short of their cap, which
  constraints bind and what relaxing them is worth, the marginal-cost dip caused
  by the labor-rate step, and why crops that lose money standalone still belong
  in the mix.
- [`figures/`](figures/) — the four figures referenced in that write-up, exported
  from `capabilities/marginal-analysis/model.xlsx`.
