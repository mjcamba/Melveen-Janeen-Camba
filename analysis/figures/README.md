# Figures

Generated by `node export-figures.js` from `maui-figure.html`. Do not edit by hand —
edit the figure source and re-export, or the paper will drift from the data.

Each file is standalone: title, subtitle, legend and source caption are baked into
the SVG, and all CSS custom properties are resolved to literal hex. A panel lifted
into the paper still names its source (AC-2) and still shows series identity without
relying on colour alone.

Source IDs (S1–S5) are the Inputs table in [`../../METHOD.md`](../../METHOD.md).

Each stem exists in four files: `.light.svg`, `.light.png`, `.dark.svg`, `.dark.png`.
Use SVG for print and for the PDF; PNG is 2× raster for slides and previews. Dark mode
is separately stepped from the same ramps and validated against the dark surface — it
is not an automatic inversion of the light palette.

**Panel-ID caution.** The display letters above do *not* match the `<svg id>` attributes
in `maui-figure.html`: display B is `#panelD`, display C is `#panelB`, display D is
`#panelC`. This dates from inserting the benchmark panel after the others were built
(see the 2026-10-01 audit entry). The `PANELS` map at the top of `export-figures.js`
is the authority; file names follow display order.

## Caveats that must travel with specific panels

- **Panel B is ecological.** Census benchmarks describe area populations; the cohort bar
  describes surveyed individuals. The Maui County figure is an ACS *five-year* estimate
  spanning 2020–2024, so it averages across the fire and cannot by construction show a
  fire effect (AC-8, AC-14).
- **Panel D does not test the income hypothesis.** It is stratified by race because no
  published source cross-tabulates food security by poverty line (G-1). Its pre-fire
  comparison is a separate survey, so it is a between-survey contrast, not causal (A8).
