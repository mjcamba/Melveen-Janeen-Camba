# Figures

This directory contains figures and visualizations from the analysis.

The figures
Figures 1–3 are your workbook's own MC-vs-price charts, exported from the MC Schedules sheet — no reconstruction, so they can't drift from the model. Figure 4 I built by sweeping each crop's bed count with the other two at zero and reading PROFIT, because claim 4 was the one assertion with no chart behind it.

Each earns its place: Fig 1 carries claims 1 and 3, Fig 2 carries claim 2, Fig 3 shows the labor step repeating in a third crop, Fig 4 carries claim 4. No decoration.
